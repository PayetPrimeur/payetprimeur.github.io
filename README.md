# Recettes Payet Primeur

Site public des recettes de la semaine (une page par produit), accessible par les QR codes des étiquettes de la boutique.

- Adresse : https://payetprimeur.github.io/
- Page d'un produit : https://payetprimeur.github.io/<produit>/

Les pages sont générées automatiquement par `_outils/generer.py` à partir de `_outils/data.json`.
La liste des produits se gère depuis l'espace admin ; les recettes sont renouvelées chaque dimanche à minuit.
Ne modifiez pas les pages à la main : elles sont réécrites à chaque mise à jour.
